# 拼豆归位 Picture Play

像素拼豆归位闯关小游戏：把画上放错的豆子挪回正确位置。手机、平板、电脑浏览器都能玩。

## 玩法

- **200 个关卡，图案零重复**：43 张手绘原创图案（爱心、水果、小动物、甜品……）+ 157 张程序生成的糖果色图案（`tools/gen-patterns.mjs`，小花/爱心/星星/蘑菇/气球/棒棒糖/兔兔/猫咪/云朵/月牙等 21 个家族 × 15 种配色），每一关的图案和名字都不一样。
- **难度真正递进**：错位率 0.5 → 0.85、空槽只有 2–12 个（越往后越少）、时间越往后越紧；打乱的豆子会连成色团，**乱点很快爆槽**。误触保护：色团比剩余空槽还长时，优先选择能触发槽内回填的豆子；没有回填机会时按容量分批，并尽量留一格缓冲（有自动化测试守门：聪明玩法全关可解、乱点总体胜率 <3%）。
- 连续色块是正确底色，凸起的圆角金字塔方豆表示错位；归位后方豆融入底色。
- 点一颗放错的豆子，上下左右连着的同色错位豆子会一起移动，两种去向互斥：
  - 有空位需要这个颜色 → 飞去空位（空位比豆子少时只飞够用的几颗，其余留在原地）；
  - 没有空位需要 → 整组进入空槽；整组放不下时自动选择一批：始终包含点击的豆子，优先带走能触发槽内回填的同组豆子；没有回填机会时批量开链并尽量留一格，其余留在原地（空槽全满时才会爆槽）。
  - 电脑上鼠标悬停会预览本次实际移动的豆子（白圈 + 数量）。
- 被腾出的格子变成闪烁空位；空槽里有它要的颜色会自动飞回来（连锁归位）。
- 空槽满了 = 爆槽失败，可以用扩槽箱 / 扫把 / 凤凰羽毛续命。倒计时用完还能继续玩，但通关只得半星。
- 点击计时器：爆破特效 + 加 10 秒，每局 3 次（超时后不能再加）。
- 星级：倒计时内通关 1 星，每关 2 个随机加星目标各 +1 星，最多 3 星；超时通关半星。三星通关可以扭蛋。

### 道具（背包全局共享）

| 常驻道具 | 效果 | 每局上限 |
| --- | --- | --- |
| 🧲 磁铁 | 选一种颜色，这种颜色的错位豆子一次归位（最多 20 颗） | 2 |
| 🧹 扫把 | 清空空槽，未归位的豆子重新洗牌，保底 20% 落对 | 2 |
| ⏳ 沙漏 | 倒计时 +30 秒 | 3 |
| 📦 扩槽箱 | 本局空槽 +4 | 3 |
| 🥢 镊子 | 接下来点 3 个格子，点哪格哪格归位 | 3 |
| 🔍 放大镜 | 10 秒内高亮现在能直接归位的豆子 | 3 |
| ↩️ 时光回溯 | 撤回最近 3 次点击 | 2 |

隐藏道具（只能连点啵啵或三星扭蛋获得，集齐 7 种啵啵变金色）：🌠 流星雨、🌈 彩虹炸弹、🧊 时光琥珀、🖌️ 魔法画笔、🧚 精灵帮帮忙、🪶 凤凰羽毛、🍀 幸运四叶草。

### 小精灵啵啵（右上角）

- 点它：爱心、星星、音符等随机特效和台词。
- 连点（0.8 秒内）：第 2–5 下之间随机掉一个道具，第 5 下必掉；每局最多 3 个，掉完歇 8 秒。
- 长按：打开许愿池，每局 3 次，每次许一种不同的常驻道具。
- 会根据你的表现夸赞、手舞足蹈、着急、鼓励、打瞌睡；超时后陪你慢跑；发呆太久会指一颗可以点的豆子。

### 特殊格子（第 4 关起）

❄️ 冰封豆（先敲冰）· ⭐ 星星豆（归位 +3 秒）· ☁️ 迷雾格（旁边归位才散雾）· 🔒 锁链豆（锁上那种颜色全部归位后解锁）· 💣 炸弹豆（步数归零前没拿走，周围已归位的豆子被打乱）

### 操作

| 操作 | 手机 / 平板 | 电脑 |
| --- | --- | --- |
| 缩放 | 双指捏合、左侧滑条 | 滚轮、`+` / `-`、左侧滑条 |
| 平移 | 单指拖动 | 按住拖动、方向键 / WASD |
| 复位全图 | ⌖ 按钮 | ⌖ 按钮、`0` |
| 跳到下一个空位 | 连点 ⌖ 按钮、点需求色条 | `Tab` |
| 用道具 | 点下方道具栏 | 道具栏、数字键 `1`–`7` |
| 查看道具作用 | 长按道具约半秒；松手不会使用 | 悬停、长按，或聚焦后 `Shift+F10` |
| 加时 | 点计时器 | 点计时器、`T` |
| 暂停 / 设置 / 退出道具模式 | ⏸ | `Esc` |

格子太小时手指点击会先自动放大，避免点错。「空位需要」提示：点按「提示」显示 2 秒，再次点击重新计时；长按约半秒可常驻显示（按钮亮起并标注「常驻」，再长按收起）；设置里的「空位提示」可以关闭该入口。
查看道具说明时游戏暂停，不消耗道具；左右滑动道具栏不会触发使用或说明。

## 自由创作与分享 · 我的小画室

地图上的「🎀 我的小画室」是自由创作与作品收藏的统一入口：进去就是你的私人小画室，墙上是收藏的作品，右上角「✨ 拼一幅新的」随时开一幅新创作。

- 上传 JPG、PNG、WebP（最大 15 MB、4000 万像素）。图片只在浏览器本地处理，不上传服务器。
- 可选最长边 24 / 32 / 48 / 64 / 96 / 128 格，或自定义输入 16–128 格的整数；调色板支持 8 / 12 / 16 / 24 色。保留图片比例与透明区域，预览会显示实际宽高，确认后再开始。纯色或全透明图片会提示重新选择。
- 自由关卡不限时，全部 14 种道具免费无限使用，爆槽也能免费续命。道具仍保留各自的使用方式，例如凤凰羽毛在爆槽时使用。
- 计时器记录实际游玩时间，暂停不计时；沙漏、琥珀不会修改完成用时。四叶草可激活，但自由模式不发放扭蛋、不改变闯关进度或背包。
- 完成后在本机保留最近 30 次用时记录，小画室展示最近 5 次；同图近期最佳按这 30 次记录计算。进行中的棋盘不持久保存。
- 新完成的自定义作品会自动收藏到小画室的作品墙，保存原始像素图、相框、文案、比例和完成用时；同一幅图重玩会更新记录，并保留已经设置的相框和摆放位置。此前只记录用时、未保存像素图的历史作品需要重新完成一次才能收藏。
- 作品墙支持鼠标/触摸拖动、调整大小与角度、暂时收起再上墙，以及奶油、樱粉、鼠尾草、星夜四种墙面和小花/星光装饰。手机可左右滑动查看整面墙；键盘可聚焦作品后用方向键微调。
- 在墙上选中作品可重新编辑相框、文案和图片比例，点击「保存相框到小画室」更新收藏，也可以重新下载高清分享图。墙名、主题和布局自动保存，可用「保存布置」手动重试。
- 普通关卡和自由关卡的结算页都有「制作我的分享卡」：奶油手帐、樱桃蝴蝶结、薄荷花园、午夜星光四种风格，可编辑文案，导出 1080×1440 或 1080×1920 PNG，并复制文案与话题。手机可打开图片后长按保存。
- 「从一言找灵感」由用户点击后请求 [一言语句接口](https://developer.hitokoto.cn/sentence/)，获取带出处的随机文学/哲理短句；这是随机语录，不是识图生成文案。5 秒超时或失败时自动使用内置文案，不影响游戏和下载。图片不会发送给一言。

## 本地数据存储（SQLite）

所有游戏数据都存在服务端本地 SQLite 单文件 `data/picture-play.db`（Node 自带 `node:sqlite`，无需额外依赖）：

| 表 | 内容 |
| --- | --- |
| `levels` | 200 个关卡的完整定义（开局布局、参数、目标、特殊格子），由 `npm run build:levels` 生成并自动写入 |
| `progress` | 闯关进度、星级、道具背包、设置（浏览器 localStorage 另有一份，多设备自动合并） |
| `custom_records` | 自由创作最近 30 次用时记录 |
| `wall_works` / `wall_settings` | 小画室作品墙的每幅作品（原始像素图 + 相框 + 摆放）与墙面布置 |

浏览器端仍保留 localStorage / IndexedDB 作为离线缓存：连不上服务端时照常游玩，恢复连接后自动合并回 SQLite。旧版 `data/save.json` 里的进度会在服务端首次启动时自动迁入。

## 本地开发

需要 Node.js 20+（服务端 SQLite 需要 Node 22.5+）。

```bash
npm install      # 或 yarn
npm run dev      # 自动打开 http://localhost:5173 ← 游戏在这里（3000 端口只是数据接口）
npm start        # 打包并用服务端托管：http://localhost:3000
npm test         # 规则引擎单元测试（含「每关都能通关」「难度递进」检查）
```

> 不要直接双击 `client/index.html`，也不要在开发模式下打开 3000 端口，那样会看不到游戏。

## 添加关卡图案

43 张手绘原创图案写在 `client/src/core/patterns.ts`，157 张程序生成的图案在 `client/src/core/generatedPatterns.ts`，13 张来自 Wikimedia Commons（CC0/公有领域，来源与许可证见 `levels/credits.json`）（由 `yarn node tools/gen-patterns.mjs` 生成，勿手改）。额外的图案放在 `levels/*.json`，会自动追加成新关卡（格式见 `levels/README.md`）。改完图案运行 `npm run build:levels` 重新生成 200 关并写入 SQLite；`tools/tune-difficulty.mjs` / `tools/naive-stats.mjs` 可以实测难度（聪明玩法可解率、乱点获胜率）。

```bash
# 任意图片 → 关卡（可加 --preview 输出预览图）
npm run art:pixelize -- 我的图.png --size 24 --colors 8 --name 小狗

# 从开放素材库搜图（Openverse，只取 CC0 / 公有领域，可自由使用）
npm run art:fetch -- "cartoon cat" "cute food" "landscape illustration" --count 6
# 打开 art/preview.html 挑选，然后：
npm run art:approve -- <key1> <key2> --name <key1>=中文名

# 重新生成 200 关并写入 SQLite（改了 patterns.ts / level.ts 之后运行）
npm run build:levels
```

素材来源和许可证会写进每个关卡 JSON 和 `levels/credits.json`，并显示在游戏「背包 · 图鉴」里。

## Docker 部署

```bash
docker compose up -d --build
# 浏览器打开 http://服务器IP:3000
```

- 存档保存在 `./data/picture-play.db`（SQLite 单文件，WAL 模式），备份只需复制 `data` 目录。
- 环境变量：`PORT`（默认 3000）、`DATA_DIR`（默认 `/data`）、`ACCESS_KEY`（可选，设置后首次打开会要求输入口令）。
- 手机、平板、电脑打开同一个地址即共享进度；连不上服务器时也能玩，恢复后自动同步。

client/src/artWallStore.ts    小画室作品墙存储（SQLite 为主，IndexedDB 离线兜底）
